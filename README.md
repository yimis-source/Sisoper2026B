# Sisoper 2026B - Sistemas Operativos

Trabajos prácticos y ejercicios del curso de **Sistemas Operativos**, donde se estudian los temas fundamentales del funcionamiento interno de un sistema operativo.

## Unidades

- **Unidad 1 - Generalidades y gestión de memoria:** particionamiento estático y dinámico, paginación, segmentación, memoria virtual y sistemas de archivos.
- **Unidad 2 - Procesos:** procesos y gestión de procesos.
- **Unidad 3 - Concurrencia y virtualización:** gestión de hilos, programación multihilos, paralelismo y virtualización.

## Proyectos

- `gestion-memoria/` — ejemplos de gestión de memoria dinámica en C (malloc, realloc, free).
- `particionamiento/` — simulador de particionamiento de memoria con los algoritmos First Fit, Best Fit, Worst Fit y Next Fit.
